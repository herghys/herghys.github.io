# Profile Photo Directory

Place your profile picture here.

### Supported File Names:
- `profile.jpg` or `profile.png` (Recommended)
- `avatar.jpg` or `avatar.png`

The website automatically checks for `assets/photo/profile.jpg` (or your chosen path/link).
- **If a photo exists:** The website automatically switches to the modern **"With Photo"** layout (featuring your circular profile photo alongside your bio).
- **If no photo is present (or fails to load):** The website cleanly collapses to the **"No Photo"** layout without any broken image icons or blank placeholders.
